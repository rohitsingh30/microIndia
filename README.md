# microIndia

Brands describe who they need in plain words and get a shortlist of real Indian creators they can defend. Every pick is backed by evidence from the creator's actual reels.

- **Status and big picture:** the governing artifact, https://claude.ai/artifact/VhXp1pDab51CxYhpuyfLcZ (source: `docs/GOVERNING.html`)
- **Live numbers:** `docs/STATE.md`, regenerated by `/sync-governing`
- **Product:** `docs/product/STORY.md` (vision, personas, core loop) and `docs/product/DECISIONS.md`
- **Architecture:** `docs/ARCHITECTURE.md`
- **How agents work here:** `CLAUDE.md`

## What's in the repo

```
apps/scraper/     Python 3.12: task runtime (sourcing, scraping, analysis), SQLite store, insight engine, API on :8787
apps/dashboard/   React + Vite: the brand app, with ops pages under /ops; built into dist/ and served by the API
docs/             governing artifact source, state, product story, decisions, architecture, archive
.claude/          project agents, skills and hooks
```

## How it works, in one paragraph
One signed-in Chrome runs with remote debugging on port 9222. Workers lease tasks from one SQLite queue:
- The **sourcer** finds candidate profiles.
- The **scraper** captures each profile and 18 posts, then keeps only real Indian human creators.
- The **analyzer** downloads reels, pulls keyframes and audio, transcribes them, and asks Claude what each reel is and why it worked. It then writes a creator dossier.

The API serves all of it to the brand app. A supervisor keeps every worker alive, and a watchdog restarts anything stuck.

## Run it

Everything runs from `apps/scraper`:

```bash
cd apps/scraper
./run/start-public-collection.sh --background   # supervisor runs every worker in run/local-workers.json
                                                 # (copy run/local-workers.example.json the first time)
PYTHONPATH=src .venv/bin/python -m microindia_scraper.status   # one-screen health
open http://127.0.0.1:8787                                       # the app
```

To start at login: `./run/install-launch-agent.sh`.

Dashboard development:
```bash
cd apps/dashboard && npm install && npm run dev    # :5173, proxies /api to :8787
npm run build                                       # the API serves dist/
```

Tests:
```bash
cd apps/scraper && PYTHONPATH=src .venv/bin/python -m unittest discover -s tests
cd apps/dashboard && npm run build && ../scraper/.venv/bin/python qa.py
```

## Working with Claude Code
Read `CLAUDE.md` first. In short:
- Any non-trivial change goes through `/plan-change`: the product-engineer agent first, then a plan from tech-lead, then the specialist agent builds it.
- `/status` gives health; `/sync-governing` refreshes the governing artifact.
- Scraping never stops. Restart a single worker with `/restart-worker`.
